# event-to-ops — Event-to-Operations Handoff

## Purpose

When an event is confirmed (Boldrin says GO, deposit received, or internal approval), generate a structured ops brief and deliver it to the property Captain agent. This is the bridge between "event confirmed" and "venue is prepped."

## Trigger

- Boldrin says: "event confirmed: {name}" or "GO on {event}"
- Or: inquiry_status changes to "confirmed" in Supabase `event_inquiries`
- Or: Suki determines event is ready for ops handoff

## Inputs

One of:
- **inquiry_id** — UUID from `event_inquiries` table
- **event_id** — UUID from `canonical_events` table
- **manual brief** — Boldrin or Suki provides event details directly (for events not yet in DB)

Plus any additional context from Boldrin (setup notes, special requirements, F&B decisions).

## Delivery

### To Captain
1. **Via `sessions_spawn`** — Send the brief to the Captain agent directly:
   ```
   sessions_spawn(agentId: "blrxzo-jr", message: "{ops_brief}")
   ```
   or
   ```
   sessions_spawn(agentId: "wtfxzo-jr", message: "{ops_brief}")
   ```

2. **Route by venue:**
   - `venue_preference` contains "Whitefield" or `zo_property_id === "wtfxzo"` → WTFxZo JR (Akhilesh)
   - `venue_preference` contains "Koramangala" or "BLR" or `zo_property_id === "blrxzo"` → BLRxZo JR (Darshan)

### To LOKI (secondary)
Send a shorter version focused on atmosphere:
```
sessions_spawn(agentId: "loki", message: "EVENT VIBE BRIEF\nEvent: {name}\nDate: {date}\nVenue: {venue}\nCulture: {culture}\nHeadcount: {headcount}\nVibe notes: {what kind of atmosphere this event needs}")
```

### To Boldrin (confirmation)
Reply in the events Telegram group confirming the brief was sent.

## Smart Defaults

When data is missing from the inquiry/event, use these defaults:

| Field | Default Logic |
|-------|--------------|
| Headcount | If null, estimate from venue capacity (Koramangala: 50, Whitefield: 70) |
| Duration | If null, default 3 hours |
| Setup time | 1 hour before start_time |
| AV | If event_type contains "hackathon/workshop/bootcamp" → projector yes |
| Seating | If "meetup/networking/happy hour" → standing. If "workshop/bootcamp" → classroom |
| F&B | If duration > 4 hours → lunch/snacks needed. If evening event → tea/coffee minimum |
| Staff | If external host → 2 staff (registration + AV). If community → 1 staff |

## Steps

1. **Fetch data** — Query Supabase for the inquiry or event record
2. **Enrich** — Apply smart defaults for missing fields
3. **Route** — Determine which Captain based on venue
4. **Generate** — Build the ops brief using the template above
5. **Deliver** — Send to Captain via sessions_spawn
6. **Notify LOKI** — Send vibe brief via sessions_spawn
7. **Confirm** — Reply to Boldrin that handoff is complete
8. **Log** — Update inquiry_status to "ops_handed_off" if from event_inquiries

## Example

Given this inquiry:
```json
{
  "host_name": "Sarnavo Saha Sardar",
  "organization": "Avalanche Team1",
  "event_type": "Team1 Connect — Avalanche ecosystem meetup",
  "event_date": "2025-06-07",
  "venue_preference": "Zo House Whitefield",
  "expected_headcount": "60",
  "budget": "1000$",
  "needs_projector": true,
  "needs_music": false,
  "needs_catering": true
}
```

Suki generates an ops brief and sends it to **WTFxZo JR** (Akhilesh), because venue = Whitefield.

The brief includes:
- Event: Team1 Connect — Avalanche
- Host: Sarnavo (Avalanche Team1)
- Date: Jun 7 | inferred 6:00 PM – 9:00 PM IST (evening meetup default)
- Venue: Zo House Whitefield
- Expected: 60 pax
- AV: Projector + screen (needs_projector = true), mic (headcount > 30)
- F&B: Catering confirmed (needs_catering = true) — details TBD, flag to Boldrin
- Seating: Standing/cocktail (meetup type)
- Staff: 2 (registration + AV — external host)

## Notes

- This skill replaces manual Telegram messages from Boldrin to captains
- The ops brief is a snapshot — if details change, re-run the skill
- For events not in Supabase (last-minute or informal), Boldrin provides details directly and Suki formats them
- If venue_preference is "Zostel Delhi" or any non-BLR/SF location, flag to Boldrin — we don't have captains for those yet
