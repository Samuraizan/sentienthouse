# Event Marketing

## Triggers
- "create event page"
- "promote event"
- "post about event"

## Purpose
Handle the full marketing pipeline for Zo House events: create the Luma listing, write compelling copy, and generate platform-specific social posts that capture the Zo vibe.

## Luma Event Page Creation

### Required Fields
- **Title:** Punchy, memorable. Not corporate. (e.g., "Founders & Whiskey" not "Networking Event #47")
- **Date & Time:** Include timezone (IST)
- **Location:** Zo House Whitefield or Zo House Koramangala (with address)
- **Cover Image:** 1200x630px, Zo-branded (request from LOKI / vibe-curator if custom design needed)
- **Description:** See template below
- **Capacity:** Set based on venue (Whitefield ~100, Koramangala ~80)
- **Approval mode:** Auto-approve unless Boldrin wants to curate the guest list
- **Registration questions:** At minimum -- "How did you hear about this?" and any event-specific questions

### Event Description Template

Structure every Luma description like this:

```
{BOLD TAGLINE -- one line that hooks}

{2-3 sentences on the vibe. What will it FEEL like to be there? Paint the picture. Use sensory language.}

---

WHAT IT'S NOT
- A networking event where you collect business cards
- A pitch fest
- {Event-specific "not" that sets expectations}

WHAT IT IS
- {What makes this unique}
- {The actual experience}
- {Why someone should clear their Friday evening for this}

---

{Practical details: schedule/flow, what to bring, food/drink situation}

---

Hosted at Zo House {location} -- a co-living space for misfits, makers, and the chronically curious.

{Optional: "Limited to X spots" if capacity-controlled}
```

**Tone:** Zo is not a coworking brand. It's a living room that got out of hand. Write like you're texting a cool friend about something you're genuinely excited about. No corporate speak. No "leverage synergies." Be real, be warm, be slightly irreverent.

## Social Media Copy

Generate platform-specific posts for each event:

### LinkedIn
- **Length:** 150-250 words
- **Format:** Hook line, story/context, details, CTA with Luma link
- **Tone:** Professional but human. Zo's LinkedIn voice is "the founder who actually replies to DMs"
- **Hashtags:** #ZoHouse #BLRxZo #Bangalore + 2-3 relevant ones (e.g., #FounderLife #CreativeCommunity)
- **Tag** relevant people/orgs when applicable

### X / Twitter
- **Length:** Under 280 characters for main tweet; thread of 2-3 tweets for detail
- **Format:** Main tweet = hook + date + link. Thread = vibe + details + "RT if you know someone who'd love this"
- **Tone:** Casual, punchy, meme-adjacent if appropriate
- **Hashtags:** Minimal. 1-2 max. #BLRxZo always.

### Instagram
- **Format:** Caption for a carousel or single image post
- **Length:** Engaging first line (shows in preview), then details, then CTA
- **Tone:** Visual-first thinking. The caption supports the image.
- **Hashtags:** Block of 15-20 in first comment (not caption). Mix of: #ZoHouse #BLRxZo #BangaloreEvents #CommunitySpace + niche tags
- **CTA:** "Link in bio" or "Comment RSVP and we'll send you the link"

### Farcaster
- **Length:** Short, crypto-native tone
- **Format:** Casual cast with Luma link
- **Tone:** Web3 native but not cringe. Zo has cred in this space -- don't try too hard.
- **Channel:** Post in relevant channels if applicable

## Posting Timeline

| Timing | Action |
|--------|--------|
| **2 weeks out** | Luma page live. First social push (LinkedIn + X) |
| **1 week out** | Second push (Instagram + Farcaster). Update Luma if details changed |
| **3 days out** | Reminder post (X + Instagram stories) |
| **Day of** | "Tonight!" post with final details (parking, what floor, etc.) |
| **Day after** | Recap teaser -- see `event-recap` skill |

## Important Notes
- Always get Boldrin's approval on the Luma page before publishing
- Never publish pricing/ticket costs on social -- drive to Luma for that
- If the event has a partner/sponsor, confirm co-branding requirements before posting
- LOKI (vibe-curator) handles visual assets -- coordinate with them for cover images and carousel designs
- All copy should pass the "would I actually click on this?" test. If it reads like a template, rewrite it.
- When in doubt about tone, re-read the Zo House Instagram and match that energy
